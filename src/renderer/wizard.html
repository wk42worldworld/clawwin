Welcome to ClawWin

OpenClaw is a powerful AI assistant that runs locally on your machine using WSL2 (Windows Subsystem for Linux). This wizard will guide you through the setup process.

What this wizard will do:

  • Verify WSL2 is installed and configured
  • Install a Linux distribution if needed
  • Download and configure the OpenClaw service
  • Start the AI assistant

Requirements

  • Windows 10 version 2004 or later (Build 19041+)
  • At least 4 GB of available RAM
  • Virtualization enabled in BIOS
  • Internet connection for downloading components
